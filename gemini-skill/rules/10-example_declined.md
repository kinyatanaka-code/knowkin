# お礼メールの完成例（見送り）

# 完成例：見送り・タイミング未達（型E）

> **この例は浦林の商談です。** 署名や名乗りは自分の名前に置き換えて読んでください。
> 文体・構成・長さの基準として使います。



## 商談の状況（この例の前提）

- ゲーム会社。EXPOで挨拶した担当者経由で、あらためて2名（関口様・山根様）へ説明する初回商談
- 冒頭で「サービスを利用したいフェーズではなく、あくまで情報収集の段階」と明言された
- 提案したのはスタンダード／ライト／エントリーの3プラン（3D空間＋オフィスツアー＋AI面談）
- 顧客が出した懸念：①学習方法 ②登録していない情報を引っ張ってきて誤情報を伝えないか ③候補者は実際どう使うのか
- 見送り理由：①タイミング ②機密上、社内撮影ができない ③情報の取り扱いが厳しく、求職者への回答も都度社内確認している状態
- 好意的な発言：両名から「個人的には面白いコンテンツ」。関口様は「AI面談だけなら現実的に見える可能性がある」とも
- 次のアクション：先方が社内にメモを残す。日程の約束はなし

## 完成メール

```
株式会社モノリスソフト
関口様　山根様

いつもお世話になっております。ネオキャリアの浦林です。
本日はお忙しい中、貴重なお時間をいただき誠にありがとうございました。

「どこでもオープンカンパニー」についてご興味を持っていただき、
率直なご感想やご質問をたくさんいただけましたこと、大変嬉しく思っております。

あらためてになりますが、「どこでもオープンカンパニー」は
候補者が採用担当者に会う前の段階で、貴社への志望度を高めるためのサービスです。

3Dで再現した働く拠点をAIの採用担当がご案内することで、
写真や求人票では伝わりきらない職場の雰囲気やリアルな働くイメージをお届けできます。
またAI面談では、残業や給与といった面接では聞きづらい質問にも匿名で答えられるため、
求人票やホームページに載せきれない情報を候補者一人ひとりの関心に合わせて届けることができます。

効率化のためではなく、候補者に「この会社に行きたい」「話を聞いてみたい」と
感じていただくためのサービスですので、
母集団形成や応募前の志望度向上、選考の歩留まり改善といった採用の入り口の部分で
お役立ていただけるかと存じます。

情報の取り扱いや社内での運用体制など、貴社ならではの厳格な基準があるからこそ、
現時点でのご導入は難しいというお話、承知いたしました。
決して「合わない」ということではなく、
タイミングとセキュリティ面での条件が整うかどうかというお話だと理解しております。
個人的には面白いコンテンツだと思っていただけたとのお言葉も、大変励みになりました。

どこかで必ずお力になれるサービスだと思っておりますので、
また貴社でご検討されるタイミングがございましたら、ぜひよろしくお願いいたします。

本日は誠にありがとうございました。
引き続きどうぞよろしくお願いいたします。
```

## この例で効いている判断

**見送りでもサービス概要を書いている。**
先方が「社内にメモを残す」と言っているため、このメールがそのメモになる。
時期が来たときに読み返して思い出せる状態にしておくのが目的。

**提案したプランの機能に沿って概要を書いている。**
この商談ではスタンダード（3D空間＋オフィスツアー＋AI面談）まで提案したので、
3D空間の話も入れている。エントリーのみの提案ならAI面談だけに絞る。

**見送り理由に反論していない。**
「情報の取り扱いが厳しい」「社内撮影ができない」は正当な制約なので、覆そうとしない。
代わりに「合わないのではなくタイミングと条件の話」と整理して、次の可能性を残している。

**関口様の「AI面談だけなら現実的」への言及を削っている。**
再提案の伏線として書きたくなるが、商談中に「その形でご提案します」と約束していない。
言っていない約束は書かない。次に接点ができたときに、こちらから持ち出す。

**「随時情報をお送りします」「社内で確認します」を書いていない。**
一度これを入れた草案を作ったが、商談で一言も言っていないため削除した。
書けば送信後に実行を求められ、実行しなければ信用を落とす。

**「ご連絡をお待ちしております」と書いていない。**
待ちの姿勢にせず、かつこちらから追う約束もしない。
「またご検討されるタイミングがございましたら」で接点を開いたままにしている。
