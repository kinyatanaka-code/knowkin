# お礼メールの型

# 型テンプレート

`[ ]` は議事録から埋める。議事録に材料がなければブロックごと落とす（空欄を残さない）。

件名・宛名の書式・資料リンク・Zoom情報は `fixed_info.md` の固定値を使う。
サービス概要は1文目だけ固定で、残りは商談内容から書く（`fixed_info.md` 参照）。
下のテンプレートで固定値が埋まっている箇所は、そのまま使ってよい。

**全型に共通する体裁**

- **1文＝1行。文の途中で折り返さない。** 長い文は2文に割る
- 意味のまとまりごとに空行を入れる。1段落は4行以内を目安にする
- 自分側のアクションを書くのは、商談でそう言った場合のみ
- 次回打ち合わせが決まっている場合、URLとミーティングIDは `fixed_info.md` の固定値を使う
  （議事録で別のツール・対面が明言されていた場合はそちらに従う）

## 型B: 初回商談・再商談未設定

時期は明確だがその場で再商談が取れなかったケース。10日以内に設定できないと自動失注になるので、**このメールの目的は日程を確定させること**。

型Aとの違い：
- 資料リンクブロックは残す
- 次回打ち合わせブロックの代わりに **【候補日】** ブロックを置く
- スケジュールパートで「なぜ今の時期に話す価値があるか」を1〜2行だけ添える（急かさない）

```
（冒頭〜サービスの位置づけまでは型Aと同じ）

（資料リンクブロックは fixed_info.md の固定値をそのまま使う）

[利用開始時期に触れ、逆算するとこのあたりで一度お話ししたい、という橋渡しを1〜2行]
30分ほどお時間をいただけないでしょうか。

【候補日】
・[日付] [時間帯]
・[日付] [時間帯]
・[日付] [時間帯]

ご都合の合う日程がなければ、[担当者名]様のご都合に合わせて調整いたします。

本日は誠にありがとうございました。
引き続きどうぞよろしくお願いいたします。

ネオキャリア
[担当者名]
```

## 型C: 再商談・上申準備

上申の準備をした商談のあと。型A・Bのような3段の説明（構造化→示唆→位置づけ）は**繰り返さない**。
軸は「合意したこと」と「上申に向けて誰が何をいつまでにやるか」。
完成例は `example_followup_meeting.md`（2回目）と `example_repeat_meeting.md`（3回目以降）。

### サービス概要を入れるかどうかは商談回数で決まる

**2回目の商談 → サービス概要を1段落入れる。**
「担当者が資料を作って上に持っていく」段階では、メール本文の概要も説明の材料になり得る。

**3回目以降の商談 → サービス概要は入れない。**
相手はもう十分理解しており、社内提案の準備そのものが議題になっている段階。
ここで概要を送っても読み飛ばされるだけで、本題である修正点とスケジュールが埋もれる。
迷ったら「相手がこのサービスを社内で説明できる状態か」で判断する。できるなら不要。

```
[会社名]
[担当者名]様

いつもお世話になっております。ネオキャリアの[担当者名]です。
[本日は／本日も]お忙しい中、[貴重なお時間／皆様の貴重なお時間]をいただき誠にありがとうございました。
[前回依頼した提供物を受領していれば、そのお礼を1文追加]
```

**スケジュールブロックについて**

型Cでは原則入れる。誰が何をいつやるかを1画面で見せるのが目的。
- 主語が自分か相手か分かるよう「（私）」「（[担当者名]様）」を付ける。全行には付けない
- 申込可否の判断日とご利用開始月は必ず入れる
- 議事録から日付が取れない行は落とす。推測で埋めない
- **相手側の登場人物を過剰に書かない。** 誰への提案かが双方分かっていれば「ご提案」で足りる
  （○「8月27日：ご提案」／×「8月27日：役員様へのご提案」）

**次回打ち合わせブロック**：次回が対面訪問・別ツールの場合はZoom情報を入れない。
次回日程が未定なら、このブロック自体を落とす。

**区切り線**：スケジュールを `＝＝＝`、次回打ち合わせを `ーーー` にして記号を連続させない。

## 型D: 受注後・キックオフ前

**この型は未検証。** 実際の受注後フロー（初期設定・学習・CS担当への引き継ぎ）と
下の記述が合っているかをあんちゃんに確認してから書く。合っていなければ指摘する。

お礼＋初期設定への橋渡し。営業トークは一切入れない。相手の関心は「で、何をすればいいのか」に移っている。
件名は「このたびはありがとうございました（ネオキャリア・[担当者名]）」を使う。

```
[会社名]
[担当者名]様

いつもお世話になっております。ネオキャリアの[担当者名]です。
このたびは「どこでもオープンカンパニー」のご導入をご決定いただき、誠にありがとうございます。

[担当者名]様に社内で進めていただいたおかげです。
あらためて御礼申し上げます。

▼今後の流れ

・[ステップ2]（[時期]）

ご導入後は専任のカスタマーサポート担当が[担当内容]を担当いたします。
```

## 型E: 見送り・タイミング未達

翻意を促さない。ただし**サービス概要は必ず入れる**。
このメールは社内にメモとして残ることが多く、後で時期が来たときに読み返される。
概要が書かれていないメールは、その時に何も思い出させない。

完成例は `example_declined.md`。

構成：

1. お礼
2. **サービス概要** — 何のためのサービスで、採用のどこに役立つか。提案したプランの機能に沿って書く
3. 見送り理由の受け止め — 反論しない。「合わないのではなくタイミングと条件の話」と整理する
4. 好意的な発言があればそこに触れる
5. 締め — 次の接点を開いたままにする

```
[会社名]
[担当者名]様
[複数名なら並べる]

いつもお世話になっております。ネオキャリアの[担当者名]です。
本日はお忙しい中、貴重なお時間をいただき誠にありがとうございました。

「どこでもオープンカンパニー」についてご興味を持っていただき、
[商談で得られたもの。質問が多かった等]、大変嬉しく思っております。

あらためてになりますが、「どこでもオープンカンパニー」は
候補者が採用担当者に会う前の段階で、貴社への志望度を高めるためのサービスです。

[提案したプランの機能を、それぞれ「何が伝わるか」で説明する。
 スタンダード／ライトなら3D空間＋オフィスツアーに触れる。
 エントリーのみならAI面談だけに絞る]

効率化のためではなく、候補者に「この会社に行きたい」「話を聞いてみたい」と
感じていただくためのサービスですので、
[採用のどの部分に役立つか。母集団形成／応募前の志望度向上／歩留まり改善など]で
お役立ていただけるかと存じます。

[見送り理由の受け止め。相手が挙げた制約をそのまま言葉にする。
 「合わないのではなくタイミングと条件の話」と整理する。3〜4行]
[好意的な発言があればここで触れる]

どこかで必ずお力になれるサービスだと思っておりますので、
また貴社でご検討されるタイミングがございましたら、ぜひよろしくお願いいたします。

本日は誠にありがとうございました。
引き続きどうぞよろしくお願いいたします。

ネオキャリア
[担当者名]
```

**この型で絶対にやらないこと**

- 「随時情報をお送りします」「社内で確認してまいります」など、商談で言っていない自分側の約束を書く
- 「ご連絡をお待ちしております」と相手にボールを預ける
- 見送り理由への反論、条件変更の再提案（次の機会に取っておく）
- 価格の再提示

## 型F: 資料送付・約束履行

**この型だけお礼メールではない。** 商談当日ではなく後日、約束した資料・見積書・動画などを送るメール。
入力は議事録ではなく「何を送るか」と「前回の商談で何を依頼されたか」。

件名は `本日はありがとうございました` を使わず、送るものが分かるものにする。

```
ご提案資料のご送付（ネオキャリア・[担当者名]）
お見積書のご送付（ネオキャリア・[担当者名]）
```

### 構成

1. 挨拶＋前回のお礼（1〜2行。長々と振り返らない）
2. **何のために使うものかを明示して**送付を伝える
3. リンクブロック
4. 反映した修正点（前回のご意見に対応したもの）
5. 確認依頼（1行。前回と同じ言い回しを使わない）
6. 次回打ち合わせ（決まっていれば）
7. 締め＋署名

```
[会社名]
[担当者名]様

いつもお世話になっております。ネオキャリアの[担当者名]です。
先日はお打ち合わせのお時間をいただき、誠にありがとうございました。

[いつ・誰との場で使うものかを明示]でお使いいただける[送付物]をご用意しましたので、
下記よりご確認いただけますと幸いです。

・[反映した修正点2]

ご確認いただいて修正が必要な点や、追加でご記載しておきたい内容があればお知らせください。

ーーーーーーーーーーーーーーーーーーーーーーー
▼次回お打ち合わせ
```

### 型Fで気をつけること

- **「何のために使うものか」を必ず書く。** 「資料をお送りします」だけだと、相手は用途を思い出す手間がかかる。
  「8月21日の取締役の方とのお打ち合わせでお使いいただける資料」のように、いつ誰との場で使うかを明示する
- **前回のメールと同じ言い回しを使わない。** 特に締め直前の依頼文。直前のお礼メールを確認してから書く
- **約束した提供物が複数あるなら、全部揃っているか確認する。**
  資料・見積書・動画のうち一部しか送らない場合は、残りをいつ送るかを書くか、あんちゃんに確認する
- 締めは「本日は誠にありがとうございました」を使わない（当日ではないため）。
  相手の社内イベントを応援する一文か、次回日程への言及で結ぶ
