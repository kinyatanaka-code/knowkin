# Gemini のスキル「knowkin」の中身

ここが Gemini のスキルの「中身」の元。直して main に上げると、Apps Script（knowkin_to_gemini.gs）が10分以内に
ドライブのドキュメント「0 目次（最初に読む）」（main.md）と「1 書き方の決まり」（rules/ を番号順につないだもの）を書き直し、
Gemini のスキルはそれを読んで動く。スキルの zip を作り直してアップロードし直す必要はない（2026-11-22 田中さん「スキルのアップデートを毎回自動で」）。

- main.md：いつも最初に読む決まり（どのドキュメントを開くか・分析・提案資料・お礼メール・書きかえの依頼）
- rules/：長い決まり（分析の進め方・完成例、提案資料の作り方、お礼メールの決まり・型・固定情報・完成例）。ファイル名の番号順につなぐ
- スキルの zip（SKILL.md）は「最初に 0 目次 を開いてその指示どおりに動く」だけ。いつ使うかを決める description を変えるときだけ、zip を作り直す
